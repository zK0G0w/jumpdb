# CLI 与控制页行为约束

修改 `internal/cli`、`internal/config`、`internal/ui` 前先读本文。面向用户的说明在 README，参数细节以 `--help` 为准；本文记录实现必须保持的约束。

## 配置

- 默认路径 `~/.config/jumpdb/config.json`；绝对路径的 `$XDG_CONFIG_HOME` 优先，未设置、为空或为相对路径时回退默认位置。
- 目录 `0700`、文件 `0600`，同目录临时文件原子替换，创建及更新后权限都保持 `0600`。
- 录入只接受终端；Token 不通过命令行明文参数传入。`token set --configure` 显式重录全部配置。
- 配置损坏或权限异常时报错，不静默重置。
- 不读取、自动迁移或删除旧 macOS 路径 `~/Library/Application Support/jumpdb/config.json`。若要读取或迁移旧工具的 `~/.ssotool_mac_conf.json`，先明确迁移行为，保留原文件，不静默覆盖。
- 生产配置要求 HTTPS 根地址，两把密钥按原始 16 字节字符串录入。合成 HTTP 服务只通过测试代码注入，不添加跳过证书校验或 HTTP 生产开关。
- 所有写入（`token set` 与控制页）一律经 `config.Update` 先读磁盘再原子替换，避免互相覆盖资源列表。
- 首版采用权限受限的本地文件即可，不把 Keychain 接入作为前提。

## CLI

- 帮助与版本输出到 stdout，退出码 `0`；参数错误输出到 stderr，退出码 `2`，提示对应子命令的帮助，**不回显参数值**。运行失败退出 `1`；`Ctrl+C` / `SIGTERM` 停止接入、关闭活跃连接、释放端口并退出 `0`。
- 资源 ID：默认把无前导零的十进制非负整数转成数字，其他非空值保留字符串；数字溢出报错。`--id-type string|number` 可强制类型；核心 `session.StringID` 不做转换。
- 只监听 `127.0.0.1`，默认端口 `9011`；不提供局域网监听开关。
- 启动时先绑定端口，再申请初始会话以获取账号；每个客户端连接另行申请新会话，不复用初始会话，初始凭据也不保证与后续会话一致。初始类型不是 MySQL 时拒绝连接。
- 分别报告“本地正在监听”“申请会话成功”“代理连接成功”“会话激活成功”“代理握手成功”；监听成功不等于数据库登录成功。
- 任一客户端在 Provider、dial、激活、握手阶段失败时，`connect` 取消整个隧道，不继续监听。
- 输出本地主机、端口、数据库类型和账号；类型、账号、密码以转义形式输出，日志不含凭据。只有显式 `--show-password` 且标准输出为终端时显示初始会话密码；不实现剪贴板复制。
- `version` 由 ldflags 注入的标签决定，本地构建为 `dev`；版本字符串只含版本号与平台，不含提交哈希、构建路径或用户名。

## Web 控制页（`jumpdb ui`）

- 只监听 `127.0.0.1` 随机端口；地址含每次运行随机生成的访问令牌，由终端打印。前台运行，随 `Ctrl+C` 退出。
- **硬性要求，须有测试覆盖**：访问令牌校验、`Host` 精确匹配（防 DNS 重绑定）、修改类请求的本页 `Origin` 与 JSON 校验。页面设置同源 CSP、禁止嵌入、不发送 Referer。
- 前端为 `go:embed` 嵌入的原生 HTML/CSS/JS，不引入 npm 或构建步骤；动态文本只以文本节点插入。
- 外观支持跟随系统、浅色、深色，默认跟随系统；选择写入配置 `theme` 字段（跟随系统为空、不写入），经 `config.Update` 保存，未完成首次配置时只在本页生效。服务端按已保存主题预置 `data-theme`，避免闪烁；配色用 CSS `light-dark()`。
- 配置语义与 `token set` 一致；秘密从不回填，门户地址可回填。
- 可多个隧道并存，阶段失败只停止该隧道；`connect` 失败即退出的语义不变。
- 每个新连接从磁盘读取 Token 以热生效；门户与密钥在隧道启动时锁定，外部变更即拒绝连接并提示重启；在页面上修改门户或密钥须先停止所有隧道。
- 观测数据（连接阶段、时长、实时字节数、结束原因、事件流水）只存内存且限量（每个隧道最近 50 个已结束连接、200 条事件）。页面和接口不返回密钥、Token、会话 ID、代理地址或原始错误。
- 初始会话密码只按显式 `POST` 返回，隧道停止后清除，不提供复制按钮。
