# jumpdb

`jumpdb` 是一个轻量的 Go 命令行工具，用于研究数据库运维会话的申请流程和本地 TCP 隧道的实现。它复用用户在网页正常登录后取得的授权 Token，申请数据库运维会话，并在本机开放一个与客户端无关的 TCP 隧道。DBX、Navicat、DBeaver、DataGrip、`mysql` 命令行等兼容目标数据库协议的客户端都可以通过它连接。

> **状态：开发中。** 目前还没有可用的命令，下文的用法是规划目标，不代表已实现的功能。

## 声明

- 本项目**仅用于研究和学习**：网络协议、AES-CBC 数据格式、TCP 转发与资源管理，以及用 Go 编写跨平台 CLI 的实践。
- 本项目**不是**专门针对阿里云堡垒机或任何特定厂商堡垒机产品的逆向工程项目，也不提供破解、绕过鉴权或越权访问的能力。
- 仓库中**不包含**任何门户地址、协议密钥、账号、Token 或真实会话数据。使用者需要在本机自行配置这些信息，并且只能用于自己**已获授权**访问的环境和账号。
- 使用者需要自行遵守所在组织的安全策略和相关法律法规。因使用不当造成的后果由使用者自行承担。

## 工作原理（规划）

1. 用户在网页正常登录，取得授权 Token 和资源 ID。`jumpdb` 不做网页自动登录。
2. 每当数据库客户端连接本地端口，`jumpdb` 都会重新申请一次运维会话，并解密会话返回的连接参数。
3. `jumpdb` 与代理服务完成握手后，在客户端和代理之间双向转发字节。

本地隧道**不是** SSH，也不额外加密流量，请不要把它当作加密隧道。

## 规划用法

```bash
# 交互录入网页登录后取得的 Token（不通过命令行参数明文传入）
jumpdb token set

# 启动隧道，默认监听 127.0.0.1:9011
jumpdb connect --id 856

# 资源 ID 可以是数字或字符串，也可以指定本地端口
jumpdb connect --id RESOURCE_ID --port 9012
```

- 默认只监听 `127.0.0.1`，不对局域网开放。
- 终端和日志不输出密码、Token 等凭据，查看或复制密码需要用户显式操作。
- 按 `Ctrl+C` 停止隧道，同时关闭活跃连接并释放端口。
- 配置文件的权限保持 `0600`。

## 首版范围

- 仅覆盖 MySQL 主流程。其他数据库类型只做识别，不承诺可用。
- 平台为 macOS（`darwin/arm64`、`darwin/amd64`），运行时不依赖 Python 或其他外部程序。
- 不包含 GUI、自动更新、后台常驻服务、Token 自动续期和资源列表同步。
